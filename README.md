# NASA Space Apps 2026: Flame in Freefall

Project started at kickoff, November 14, 2026, 09:00 CST. The team's concept is not written yet.

## Data
- `data/psi/investigations.json`: public metadata for 25 NASA PSI combustion records (the 20 investigations named in the challenge statement, on 19 records, plus 5 related ones). Every field gives its source URL and a verbatim quote, or is null.
- `data/psi/notes.md`: gaps and conflicts between sources.
- `data/raw/`: the downloaded source pages and files (not in git).

## Use of AI
Claude Code (Anthropic) collected and checked the PSI metadata above. The project idea is the team's own.
